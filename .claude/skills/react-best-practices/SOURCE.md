## Note for this template

This project is a client-side React app inside a Chrome extension: there is
no Next.js, no server and no React Server Components. Rules about server
rendering, API routes, RSC, SWR fetching or Next.js-specific APIs don't apply.
The rules on re-renders, rendering, bundle size, JavaScript performance and
client-side patterns do.
